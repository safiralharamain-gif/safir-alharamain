# ربط سفير الحرمين بجوجل — مرحلة أولى
**الحالة: ملفات مصدر جاهزة للإعداد، ولم يتم نشر نظام الحجز أو ربطه بحساب جوجل بعد.**

## 1. إنشاء جداول خاصة
أنشئ Google Sheet جديدًا خاصًا باسم سفير الحرمين. افتح Extensions > Apps Script، والصق admin/Code.gs وأضف ملف HTML باسم Sidebar بمحتوى admin/Sidebar.html. احفظ، حدّث صفحة الجدول، ثم اختر سفير الحرمين > تهيئة الجداول. سيُنشئ «عروض العمرة» و«طلبات الحجز» و«الإعدادات».

## 2. لوحة إدارة مدير واحد
لا تنشر مشروع الإدارة كتطبيق ويب. افتح اللوحة من القائمة داخل Sheet المرتبط، ولا تشارك الجدول إلا مع حساب المدير. بقاء الصلاحيات على حساب المدير ضروري.

## 3. خدمة الحجز
أنشئ مشروع Apps Script ثانيًا منفصلًا، والصق public/Code.gs وملف HTML باسم Booking بمحتوى public/Booking.html. اضبط Script Properties: SHEET_ID = معرف جدول الإدارة (من عنوان Google Sheet). انشر **مشروع الحجز فقط** كتطبيق ويب يعمل بصلاحية المالك، وصول لأي شخص، بعد مراجعة الأمان والموافقة على الأذونات. احفظ رابط /exec.
**مهم:** حساب المالك هو الذي يمنح مشروع الحجز إذن الوصول إلى الجدول. هذا النموذج التجريبي يحتوي على تحقق من الإدخال وحقل مصيدة للبوتات، لكنه ليس نظام منع إساءة استخدام متكاملًا؛ أضف rate limiting / CAPTCHA وحماية إساءة الاستخدام قبل نشره على نطاق واسع.

## 4. ربط الموقع
الرابط /exec الخاص بالحجز يفتح صفحة الحجز المستقلة. اربط زر الحجز في الموقع الرسمي به بعد الاختبار. لا تضع رابط لوحة الإدارة العامة في GitHub؛ ولا تنشر أي مفتاح خاص أو كلمات مرور في JavaScript.

## 5. العروض
جدول «عروض العمرة» يحتوي id,title,price,departure_date,duration_days,hotel,description,status,updated_at. جدول «عروض العمرة» للصفوف المنشورة فقط يجب توفيره للواجهة العامة عبر خدمة قراءة عامة منفصلة لا تكشف «طلبات الحجز» أو «الإعدادات». هذا الربط لم يُنشأ بعد.

## 6. الدومين
لا تغيّر main أو CNAME أو DNS في هذه المرحلة. احتفظ بـ https://safiralharamain.com/ كرابط QR ثابت.

## تنبيه الخصوصية
نموذج الحجز يجمع بيانات شخصية. استخدم سياسة خصوصية واضحة، وقلل الوصول إلى البيانات، واحتفظ بنسخ احتياطية وحدد مدة الاحتفاظ المناسبة. لا تشارك Sheet مع الجميع.
